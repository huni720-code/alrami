# STEP 2 — 약정 온보딩 화면 스펙 (Claude Code 구현 레퍼런스)

> 토스급 UX 목표: 한 화면 한 목적, 키보드 최소(칩 선택), 큰 탭 타깃, 스크롤 없이 핵심.
> 색: 앱 기존 emerald `#10b981`(선택/주요 버튼), 선택 칩 배경 연녹 `#E1F5EE`+글자 `#0F6E56`.
> 계산(종료일 등)은 전부 백엔드. 프론트는 표시·입력만. 모바일 375px 기준.

---

## 화면 1 — 휴대폰 약정 입력 (추정)

목적: 날짜 입력기 없이 **칩 선택만으로** 약정 종료일을 추정.

구성(위→아래):
1. 상단 라벨: "1 · 휴대폰 약정" (11px, tertiary)
2. 제목: "약정 정보를 알려주세요" (16px/500)
3. **통신사** (라벨 12px secondary) → 칩: `SKT` `KT` `LG U+` `알뜰폰` (단일선택)
4. **언제 가입했어요?** → 칩: `올해` `작년` `재작년` `그 이전` `모름`
5. **약정 몇 년?** → 칩: `2년` `3년` `30개월` `무약정` `모름`
6. **추정 결과 카드**(배경 `--color-background-success`): 라벨 "약정 종료 (추정)" + 큰 텍스트 "○○○○년 ○월쯤"
   - 입력 바뀌면 백엔드 호출로 즉시 갱신. (end_date = start_date + term_months, 백엔드 계산)
7. 주요 버튼(emerald, 흰글자, 풀폭): "네, 맞아요"
8. 하단 텍스트 링크: "정확히 확인할래요" → 화면 3(확인 도우미)로 이동

규칙:
- 칩 선택형(드롭다운/날짜피커 지양). 선택 칩 = emerald 테두리+연녹 배경+`#0F6E56` 글자.
- "모름"이 있어도 추정·알림은 진행(빈칸 금지). 결과는 estimated로 표기.
- 단정 금지("~쯤"). 약정 중이면 위약금 안내 문구 옵션.

## 화면 2 — 품목 추가 (아이콘 그리드)

목적: 지원금 걸린 다른 약정을 **자기 것만 선택**해 추가. funnel 마찰 최소.

구성:
1. 상단 라벨: "2 · 약정 더 있나요"
2. 제목: "해당하는 것만 골라요" + 보조문 "지원금 걸린 것만. 나중에 알려드릴게요." (12px secondary)
3. **아이콘 그리드 2열**: 휴대폰(완료·체크 표시), 인터넷(ti-wifi), TV(ti-device-tv), 정수기(ti-droplet),
   렌탈가전(ti-armchair), 비데(ti-bath). 미선택은 "+ 추가", 선택 시 emerald 강조.
   - 아이콘 탭 → 그 품목 상세 입력(화면 1과 동일한 칩 흐름)으로. 한 번에 다 받지 말 것.
4. 주요 버튼: "다음" / 하단 링크 "없으면 건너뛰기"

규칙: OTT·일반구독 아이콘 없음(지원금 없어서 대상 아님). category는 백엔드 Contract.category와 1:1.

## 화면 3 — 약정일 확인 도우미

목적: 약정일 모를 때 **원탭으로 확인 경로** 주고 그 자리에서 입력. (자동 조회 불가)

구성:
1. 상단 라벨: "약정일 확인 도우미"
2. 제목: "약정일 모르세요?"
3. **회사 선택 칩**: SKT/KT/LG U+ (+ 알뜰폰/렌탈사). 선택 시 아래 카드 갱신.
4. **확인 카드**:
   - 큰 전화 버튼(emerald, ti-phone 아이콘): "114 전화하기" → `tel:` 링크(본인폰 단축번호).
     타사/유선이면 center_number 사용. 데이터: `docs/약정확인_도우미.md`.
   - 보조문: "또는 T월드 앱 > MY > 나의 가입정보에서 약정기간 확인" (회사별 app_name+check_path)
   - 안내(11px tertiary): "자동 조회는 안 돼요. 확인 후 아래에 입력하면 끝이에요."
5. **입력칸**: "확인한 약정 종료일" (예: 2027-03) + "입력 완료" 버튼.
   - 정확 입력 시 accuracy=confirmed로 승격.
6. 미확인 회사(SK매직 등 빈칸): 전화/메뉴 대신 "고객센터 검색" fallback. 추측 금지.

---

## 공통
- 컴포넌트: 칩(선택형), 큰 풀폭 버튼(emerald), 입력칸 1개, 결과 카드. 한 화면에 이 이상 넣지 말 것.
- 접근성: 전화 버튼은 실제 `tel:` 링크. 탭 타깃 ≥44px.
- 데이터 출처: 확인 도우미 = `docs/약정확인_도우미.md`. 종료일/ D-day = 백엔드(STEP 1 Contract).
